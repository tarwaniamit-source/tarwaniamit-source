### 🧭 How I work

- **Problem before solution.** I write the problem statement and the
  non-goals first; scope discipline is what gets v1 out the door.
- **Prototype to learn.** A clickable prototype answers questions a deck can't.
  Each project here is something you can actually use, not a mockup.
- **Decisions, not just features.** I document the trade-offs (e.g. *builder vs.
  runner*, *placeholders vs. stored secrets*) so the "why" is reviewable.
- **Measure what matters.** Every product case study names a North Star and the
  funnel I'd instrument to validate it.
